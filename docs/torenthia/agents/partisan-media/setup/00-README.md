# Partisan Media Editorial Agent — Setup v1.0

**Status:** Agent creation package; editorial infrastructure only. Not a World publication or grant of independent publishing authority.

## Purpose
Create **one** independent partisan-media agent for Torenthia, capable of maintaining *three differentiated editorial viewpoints* (right, center, left) without creating six party agents or displacing the Federal and State editorial agents.

This is a **media agent, not a political-parties agent**. Its job is political coverage, argument, scrutiny, opinion, reporting proposals and sustained editorial narratives. It does not speak as elected officials or political parties.

## Setup order
1. Give the target agent `01-SYSTEM-INSTRUCTIONS.md` as its permanent role instruction.
2. Give it `02-SOURCE-AND-CONTINUITY.md` as a source guide, not as a substitute for reading repository evidence.
3. Give it `03-EDITORIAL-DESK-AND-SUBMISSIONS.md` for workflow and voice requirements.
4. Ask the agent for a concise initialization acknowledgment specifying its authority boundaries. Do **not** run a qualification exercise before initialization.
5. After initialization, give it `04-QUALIFICATION-TEST-01.md`; assess subsequent tests individually.

## Owner / VP approval
The agent may research, propose and draft. Only central editorial can approve canon, publication, identifier allocation, fictional time advances, and cross-agent actions. It may not edit GitHub, publish, or create official political acts.
