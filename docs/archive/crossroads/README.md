# Archived Living Crossroads installments

`thoss-crossroads.json` is the original sealed **The Dark Horse** game, preserved byte-for-byte and withdrawn from public access at the author’s request.

This directory is excluded from the Eleventy public build. Do not add it to passthrough assets or public game selection. Historical public links now report that the installment is unavailable or archived; Korda remains playable.

The complete last public implementation is preserved in Git at commit `c0de2e035d44202fc7ee6d667bd5023e0d60b924`. Legacy engine regression tests still use this archived data, so preservation can be checked without republishing it. This retirement does not remove Thoss’s news coverage or alter canon.
