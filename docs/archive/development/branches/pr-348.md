## Decisions and rejected approaches
- **Rejected:** R2 lifecycle (prefix expiry) rules on `submissions/`. They would also delete held and unverified items, which #331 rules out.
- **Rejected:** fully automatic deletion. A merged manifest is the one human approval per batch.
- **Chosen:** GET writes on the relay. Accepted because the relay answers only behind Vercel Authentication and the Worker rechecks every purge. Test items (title starting with TEST) skip the 30-day wait.
