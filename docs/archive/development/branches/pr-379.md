# Branch history — newsroom/read-endpoint

**Original branch:** `newsroom/read-endpoint`
**PR:** [#379](https://github.com/jcr0916-hue/federatedrepublic/pull/379)
**Status:** proposed (draft; awaiting John)

## Purpose
Let the Central Editor's shell read the newsroom inbox as files. The workspace reaches thefederatedrepublic.org but not `workers.dev` or `*.vercel.app`, so reads went through the Vercel connector and the editor's context, which blocked scripting (edit log, pre-filing lint, staging).

## Shipped in this PR (on merge)
- `api/newsroom-read.js`: read-only `list`, `read`, `readmany` (up to 10) on the public domain, gated by `NEWSROOM_READ_TOKEN` (constant-time SHA-256 digest comparison; unset or under 24 characters disables the route; every refusal is the same 404). Uses `NEWSROOM_EDITOR_KEY` server-side; no write path.
- `scripts/newsroom-fetch.mjs` (`npm run newsroom:fetch`): saves filings and each article's story text to files. Self-contained so it does not depend on #378.
- `vercel.json` build and route; `docs/torenthia/NEWSROOM.md` section; tests in `scripts/newsroom-read.test.mjs` and `scripts/newsroom-fetch.test.mjs` (in `npm run test:newsroom-inbox`).

## Results and verification
`npm run test:newsroom-inbox` (23 tests) and the full `npm run world:publish-check` pass. Not yet tested against the live Worker: that needs the token set in Vercel after merge.

## Decisions and lessons
- Chosen over allowing `workers.dev` in the editor's network settings (would put the full editor key, with review and purge, in that environment), mirroring drafts into the repo (the repo is public, so unpublished drafts and reserved-continuity pitches would be exposed), and the Cloudflare connector (bucket-level only).
- A leaked read token exposes unpublished drafts and changes nothing; rotation is one Vercel variable plus the editor environment's copy.
- After merge and token setup: confirm the scheduled-task environment reaches the domain with a test run, then update the daily review prompt to fetch with `npm run newsroom:fetch` and run the edit log on the draft files.
