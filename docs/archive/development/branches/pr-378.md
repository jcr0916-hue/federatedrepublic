## Purpose

## Shipped in this PR (on merge)
- `api/_newsroom-triage.js`: the window starts at the previous report's `[through <time>]` (fallback: its filing time minus 20 minutes, then 26 hours; never more than 7 days back); canon filings read in full (14,000 characters); ideas filed as articles or over 700 words flagged in code; `newsroom-run` reports are never sorted; Monitors and Corindal reports of kind `report` bypass the model (roster `triage.passThroughReports`).
- `api/_newsroom-core.js`, `api/newsroom-run.js`: each scheduled run files one `newsroom-run` report with every desk's outcome and reason; a desk with an open assignment may skip only by naming what blocks it.
- `docs/torenthia/agents/NEWSROOM-RULES.md`: first-week corrections checklist, pitch discipline (150–300 words, kind `pitch`), "what is new" test. `RECORDS-BRIEF.md`: signatory and near-name checks. `DESK-CLOCK.md`: dry next-step menus per thread and a "name the step your piece adds" rule.
- `scripts/newsroom-edits.mjs` (`npm run newsroom:edits`) and `docs/torenthia/agents/EDIT-LOG.md`: word-level draft-versus-published metric, week 1 measured (3%–36%, median 16%).
- `docs/torenthia/NEWSROOM.md`, `IDEA-BOARD.md`: the changes above and the idea-board duplicate guard (skip an idea whose `sourceKey` is already carded).

- Root cause of the Nov 22 re-sorting: the Central Editor archives inbox items at the 17:05 run, after the 16:37 triage, so a "still PROPOSED" filter cannot work; the cutoff time does.
- Corindal's Nov 19 silence is unexplained (logs gone; no `NEWSROOM_KEY_CORINDAL` set, so not a key mismatch). The run report will show Thursday Nov 26's outcome; if it is a skip, the reason is now on record.
- The edit metric counts renames per mention and ignores bylines (outside the story text), so it reads as a size, with `NOTES.md` as the substance.
- Not done: per-desk assignments to move clock threads. Desks get the clock's next-step menu instead; the Federal desk's open step-1 pitch (Panel notice) is the main mover for Monday.
- Follow-ups for the scheduled Central Editor: archive the `newsroom-run` report each run; log edits at publication.
