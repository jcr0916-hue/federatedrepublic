## Purpose
Record John's design decision to change §12.1's education sentence from "Parents" to "Parents or guardians", so children who are wards of the State or in guardianship are covered.

## Shipped in this PR (on merge)
- `docs/WORKING-CONSTITUTIONAL-AMENDMENTS.md`: new "Proposed amendment 2" with exact wording, scope, rationale, rejected alternatives and downstream updates; Updated date set to 23 November 2026.

## Decisions
- Recorded as a working amendment, not applied to the adopted text: the file's own rule is that adopted text is not modified silently and that settled proposals reach the Constitution in a release.
- Wording chosen by John: "parent or guardian", matching §5.3. Rejected: "a child's guardian" alone (can read as removing parents), "legal custodian" (custody-law narrow), "caregiver" (no legal standing). The proposal was first offered as "a child's parent or legal guardian"; John chose the plural form that matches §5.3's phrase.

## Results and verification
Documentation-only change; no site build or constitutional file was touched, so no site check applies. Wording and downstream-file list were checked against `constitution_data.json`, `annotations.json` and the previous amendment's file set (PR #241).

## Unresolved
Where the State is the guardian, the clause protects less; the proposal notes this and does not try to solve it.
