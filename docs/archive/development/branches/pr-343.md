# Branch history — newsroom/editor-relay

**PR:** [#343](https://github.com/jcr0916-hue/federatedrepublic/pull/343)

## Purpose
Let the Central Editor review the newsroom inbox from its cloud workspace, which can reach thefederatedrepublic.org but not workers.dev.

## Shipped in this PR
- `api/newsroom-inbox.js`: a read-only relay (GET list, GET read). It attaches the editor key from the Sensitive Production variable `NEWSROOM_EDITOR_KEY`, and answers only on `*.vercel.app` hosts, which Deployment Protection limits to John's Vercel account; the public domain gets 404. The editor calls it through the Vercel connector.
- `vercel.json`: build and route for the relay.
- `scripts/newsroom-inbox-relay.test.mjs` (4 tests), added to `test:newsroom-inbox`.
- `docs/torenthia/NEWSROOM.md`: Editor relay section.

## Setup (John, 2026-11-16)
`KEY_EDITOR` on the Worker was rotated. The same value is stored in Vercel as `NEWSROOM_EDITOR_KEY` (Sensitive, Production). Vercel forces every variable to Sensitive, so the relay uses the key at runtime instead of the editor reading it. If Deployment Protection is ever turned off, delete the variable.
