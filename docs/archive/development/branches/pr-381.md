## Shipped in this PR (on merge)

## Decisions
- Chose a plain mailto link over a contact form. A form needs a new Vercel function, an outgoing-mail provider account, an API key held in Vercel and spam handling; that is more machinery than this audience needs. Revisit only if the mailto link proves clumsy.
- The new address forwards through Cloudflare Email Routing (a dashboard setting; no Worker required). Forwarding receives mail only; sending as hello@ would need a separate outgoing-mail service and is not part of this change.
