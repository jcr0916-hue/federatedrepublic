## Purpose
John approved a build-time image optimization after the image audit showed the deployed site carried about 29 MB of large truecolor PNGs (portraits, cityscapes, the 1024 px seal shown at 32 px on most pages). Readers download those files; the repository copies are masters and stay as they are.

## Shipped in this PR (on merge)
- `scripts/optimize-site-images.mjs`: runs after Eleventy (`npm run build`) and rewrites large PNGs inside `_site` as palette PNGs. Same URLs and pixel sizes; `seal.png` is the one resize, to 640 px (covers the 32 px header use and the 300 px/600 px retina use on two pages).
- `scripts/optimize-site-images.test.mjs` (7 tests), `test:optimize-images` script, added to `world:publish-check`.
- `sharp` as a devDependency (`package.json`, `package-lock.json`, about +600 lines).

## Safeguards
- A result is kept only if it is at least 15% smaller and at least 38 dB PSNR against the original (flattened over white, so transparent pixels do not distort the score). Otherwise the original stays.
- Palette PNGs are skipped (`metadata().isPalette`), so a second run rewrites nothing.
- Files under 100 KB, favicons and apple-touch icons are skipped (the seal is the exception, for the resize).
- If `sharp` cannot load, the step warns and the deploy proceeds with unoptimized images.
- Source artwork under `images/` is never opened for writing.

## Results and verification
Fresh build: 18 of 19 PNGs rewritten, 29.4 MB to 7.4 MB; `_site` 50 MB to 28 MB. `seal-watermark.png` kept (gain under 15%). Side-by-side crops of a landscape, a portrait and the seal showed no visible banding. `npm run world:publish-check` and `npm run build` pass locally.

## Known limitations
- PNG only. JPEG, SVG and WebP files are not touched.
- Vercel builds on Node 24.x and local runs use Node 22; `sharp` ships prebuilt binaries for both, but the first Vercel build is the real test of the step. A failure there degrades to the old behavior rather than failing the deploy.
- The 43 unreferenced images (about 82 MB) never deploy and are not affected.
