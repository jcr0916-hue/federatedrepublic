## Purpose
John asked for three to five State constitutional tests per State across the Republic's first twelve years, on the idea that each State wrote its constitution and the record shows it being tested over time. At the time of this PR the site publishes 19 State tests (Kelvant 3; Arvane, Corindal, Merath, Norvane, Orath 2 each; Aldenmere, Caldenmere, Harren, Rhovane, Selvane, Varek 1 each). John answered yes to a pitch round.

## Shipped in this PR (on merge)
- An open assignment (kind `pitch`, track `idea`) in the `ASSIGNMENTS.md` of the eleven States below three, owing 17 pitches in total so every State reaches three. Kelvant has none.
- Each assignment names that State's published tests (title, Year and Month, sections) so the desk avoids repeating them, and asks for: a working title, a Year 1-12 date, the sections under strain checked against the full text, and two sentences on the outcome. A desk may pitch fewer and say which section is the limit.

## Decisions
- Target three first, not five; the pitches show how much each constitution supports before any push toward four or five.
- Pitches only. John's GO on the idea board turns a pitch into a writing assignment, so nothing is drafted or numbered here.
- Corindal (Statehood Audit work) and Norvane (the optional Argent Ridge idea) keep their existing open items first.
- Dates stay in the past (Years 1-12); the fictional date remains Year 14, Month 2.

## Known limitations
- Backdated tests run through the same canonical-history path as the existing ones; if a pitch implies a cross-jurisdiction effect, the editor trims it before it reaches John.
- An open assignment makes a desk run weekly until it moves to Done; the editor moves each to Done once its pitches are on the idea board.
