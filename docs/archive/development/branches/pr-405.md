## Purpose
John asked that States show records "like things that states would have on their record system." State records desks already file those entries weekly, but they published as "National Record System" with empty `worldJurisdictions`, so State profiles and the coverage report never showed them.

## Shipped in this PR (on merge)
- `_data/recordSystems.json`: the 12 State record-system names, taken from the State constitutions (Aldenmere's constitution names none; it keeps the name its desk already used, "Aldenmere State Record").
- `worldRecordSystem` front matter and a publishing-check rule (`lib/world-publishing.mjs`).
- `--record-system <State>` in `npm run world:new` (`lib/world-authoring.mjs`, `scripts/new-world.mjs`).
- State profile section per record system (`_includes/state-profile.njk`), `stateRecords` filter and a `stateCoverage` exclusion (`eleventy.config.mjs`), Source filter options on `torenthia-record.html`.
- Backfill of the 42 State entries that name their record system (outlet, jurisdiction tag, system, header line).
- Tests in `scripts/world-publishing.test.mjs`; docs in `docs/torenthia/PUBLISHING.md` and `NEWSROOM.md`; `COVERAGE.md` regenerated.

## Decisions
- Presentation only: entries keep their shared NRS numbers. Separate State numbering is a larger build and stays a later option.
- Territories are excluded: their Compacts make the National Record System the authoritative record (Korda Art. 10, Solara Art. 10), so they stay on NRS and gain no field. Korda's routine internal returns stay off the site.
- Older State-level NRS entries that never carried a "Record system:" line are not backfilled (their State is not stated on the page). They can be tagged later case by case.

## Results and verification
`npm run world:publish-check` passes locally. The built Aldenmere profile and the Record page's Source filter were opened in a browser: the section lists six entries and the profile link returns six matching records.

## Known limitations
- The cloud editor must stage future State entries with `--record-system` (documented in NEWSROOM.md); entries staged without it still publish as National Record System.
- Mundane records never light the States map, so the map is unchanged.
