# Branch history — newsroom/run-reliability

**PR:** [#336](https://github.com/jcr0916-hue/federatedrepublic/pull/336) · follows [#335](pr-335.md)

## Purpose
Small reliability changes drawn from an external review on 2026-11-16, with the first editorial feedback to the Federal desk.

## Shipped in this PR
- **Clear failures:** the run returns HTTP 500 when any desk fails. Vercel doesn't retry failed path runs, so this only changes what the schedule history and error rate show.
- **Once-a-day guard:** before any model call, the desk lists its own inbox folder and skips if it already filed that UTC day. Duplicate deliveries and repeat manual runs cost nothing.
- **Source pinning:** every file in a run is read at one resolved `main` commit, recorded as `commit:<sha>` in `sourceRefs`.
- **Federal notes:** the first draft is held as a status recap. The shared rules now ask for stories, not status reports.

## Rejected from the review
- A durable execution lock and a new store: the inbox listing already answers "did this desk file today."
- A code-level spending ceiling: the Gateway's free credit cap, or a Gateway budget setting, covers it.

## Verification
16 offline newsroom tests pass.
