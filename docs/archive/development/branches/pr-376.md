# Branch history — feat/torenthia-hub-and-record-clarity

**PR:** [#376](https://github.com/jcr0916-hue/federatedrepublic/pull/376) (draft)

## Purpose
John approved the recommendations made after his note that the Torenthia page was getting overloaded and hard for a newcomer to navigate: give the Torenthia page one job (point a visitor to the right door), fold overlapping "what's new" sections into one, and stop routine filings from burying the news on The Record. (The map and flag change shipped earlier in #375.)

## What is in it (shipped when merged)
- **Torenthia page** (`torenthia.html`): the hero's link row becomes three doors: Follow the stories (to The Republic Now on the same page), Read the news (The Record) and Explore the place (States map); "The first twelve years" and the Atlas become a quiet "Also" line. Section order is now hero, The Republic Now, Latest from Torenthia, the Executive dials and Open Question, then "See the Republic" last. "Reporting from the States & Territories" is removed; its job is a single "See which places have news" link to the lit map. "Dispatches / Voices" becomes a compact "Voices & dispatches" list (the four newest dispatches not already among the four Latest cards) inside the Latest section; it keeps `id="dispatches"` so the menu item still works. The Latest section's four cards are unchanged, so the discovery check on them still holds.
- **The Record** (`torenthia-record.html`, `discovery.js`): search and filters come first, with an "Include routine filings" checkbox. By default the 88 records marked routine (`worldMundane`) are hidden, and the count line says how many are hidden. They appear when the box is checked (`?routine=1`), when a search term is entered, or when the Civic Life type is chosen. The source cards moved into a collapsed "Browse by source" disclosure below the filters so results start on the first screen. The four filters sit on one row on desktop.
- Small fix: "The Open Question" heading on the Torenthia page was dark text on the dark band (pre-existing, invisible); it now uses the light heading color.
- Eleventy filter `voices` (`eleventy.config.mjs`); styles in `site.css`; new rendered checks in `scripts/check-discovery.mjs` (three doors, voices never repeat Latest and are dispatches, routine toggle present, every routine record marked).

## Tests and results
`npm run world:publish-check` passed. Playwright (desktop and 390px): default Record view 228 matching / 24 shown / 0 routine visible / 88 hidden; checking the box gives 316; searching "pump" finds the routine record; `?routine=1` restores the toggle; the Korda place filter works and says "1 routine filing hidden"; the source carousel works inside the disclosure; no page errors. Not checked on production before merge.

## Decisions
- Routine records are hidden only in the default view; search, the Civic Life type and the toggle bring them back, so nothing is lost and no search comes back empty because of the default.
- Source cards stay available but collapsed rather than removed. Rejected: leaving them above the filters (pushed results below the first screen).
- The carousel moved to the end instead of being deleted.

## Known limitations / unresolved
- "Include routine filings" is not remembered between visits.
- The State and Territory place filter hides routine filings by default too (the hidden count is shown).
- The Executive dials and Open Question band is unchanged apart from the heading color.
