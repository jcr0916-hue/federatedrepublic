## Deletion prerequisites

1. Verify each candidate branch tip still matches the SHA in this manifest; stop if it moved.
2. Confirm complete branch-tip reachability from `archive/legacy-project-material` (zero commits ahead of archive) and intact unchanged archive tree.
3. Confirm the branch is not used by a live deployment, preview environment, workflow, draft/open PR, or operational dependency.
4. Consult five batches of branch histories and the [AI experiment decisions](AI-EXPERIMENT-DECISIONS.md) and [constitutional/publishing decisions](CONSTITUTION-PUBLISHING-DECISIONS.md); preserve any overlooked run artifacts or results.
5. Review and separately approve a concrete list of branch refs for deletion; do not delete either permanent branch. Prefer small, auditable batches.
6. After any deletion, verify both permanent refs and essential active site/Constitution checks.

**Why preserve outcomes as well as commits?** Git retention prevents loss of the original evidence, while the decision registers avoid repeating benchmarks and prior design experiments. The two serve different purposes.
