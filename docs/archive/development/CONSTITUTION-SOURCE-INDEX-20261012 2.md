1. Walk the published **first-parent** history of `main` from the last legacy archive through the new automation baseline. Identify every transition that replaced authoritative JSON and/or Markdown.
2. Retrieve both original blobs, not re-renderings with current code. Validate the pair against the *historical* renderer where possible; log separate exceptions for any drift.
3. Save verified exact pairs with the archive's naming, immutability and metadata rules; distinguish timestamp of supersession from date an edition first became current.
4. Maintain a manifest mapping archive filenames to original commit/tree SHA, blob SHA and verification status. Flag incomplete historical editions explicitly without fabricating a partner file.
